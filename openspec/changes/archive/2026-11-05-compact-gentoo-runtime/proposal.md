# Proposal

## Why

Общий Gentoo runtime занимает 1 434 586 421 байт: он включает полную stage3, дерево установки пакетов и инструменты сборки. Нужно уменьшить образ, сохранив sync и подготовку metadata, и отделить редко обновляемую базу от кода worker.

## What Changes

- Добавить Gentoo-базу для linux/amd64: stage3 по digest, датированный snapshot с SHA-256 и проверкой подписи, Git из исходников с фиксированной версией и USE.
- Сформировать конечную файловую систему из установленных runtime-пакетов и их зависимостей, без дерева ebuild для установки и компиляторов.
- Собирать worker и sync поверх этой базы; обеспечить локальную сборку без registry и отдельную подготовку базы для будущей публикации.
- Проверить уменьшение размера, sync, healthcheck, права и реальную генерацию metadata на основном репозитории, исторической версии и overlay.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

Нет: контракты приложения и сетевые/volume-границы Compose сохраняются. Это изменение сборки; `.openspec.yaml` использует `skip_specs: true`.

## Impact

`gentoo/`, общий build Compose, документация и сценарий проверки образа. HTTP API, Go-код и хранимые данные не меняются. Docker Hub, учётные данные, commit и push не входят в выполнение. Критерий размера — конечный образ меньше исходных 1 434 586 421 байт; фактический результат фиксируется после сборки.
