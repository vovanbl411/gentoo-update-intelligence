## ADDED Requirements

### Requirement: Отображение пересборок
UI SHALL показывать R как «Пересборка» с целевой версией. При отсутствии установленной стороны SHALL явно сообщать, что она не указана и сравнение до/после недоступно.

#### Scenario: Пересборка без установленной версии
- **WHEN** результат содержит reinstall с пустым installed
- **THEN** карточка показывает Пересборка, target и отсутствие установленной стороны без выдуманной before

### Requirement: Явная полнота разбора
Для Parser partial или unsupported UI SHALL показывать заметное предупреждение, что анализ охватывает только распознанные записи и отсутствие findings не характеризует весь вход. Сводка SHALL называться «Распознано пакетов»; общий счётчик SHALL показываться только при наличии сводки Portage.

#### Scenario: Прежний частичный результат
- **WHEN** открыт сохранённый partial или unsupported
- **THEN** UI показывает предупреждение, распознанное количество и общий счётчик только из summary без автоматического повторного анализа

### Requirement: Независимое ограничение metadata
Ограниченность metadata comparison SHALL обозначаться отдельно от полноты разбора.

#### Scenario: Полный разбор с недоступным сравнением
- **WHEN** Parser parsed, но metadata comparison недоступно
- **THEN** UI отдельно обозначает ограничение сравнения и не называет разбор неполным
