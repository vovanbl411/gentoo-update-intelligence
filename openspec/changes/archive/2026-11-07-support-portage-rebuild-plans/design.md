## Context

Пользовательский fixture содержит 43 строки без сводки: 36 U и 7 R. Исходный текст сохраняется.

## Goals / Non-Goals

Цель — parsed без диагностик и сохранение всех явно показанных фактов. Установленное состояние вне плана, причины пересборок, оптимизации и автоматический переразбор сохранённых результатов не входят в задачу.

## Decisions

Единый разбор размера сначала проверяет группы цифр, затем удаляет запятые и проверяет int64 overflow. Счётчики сводки также проверяются на overflow.

R не копирует target в installed. При отсутствии installed ChangeReport сохраняет INSTALLED_CONTEXT_MISSING и проверяет идентичность только after; сравнение недоступно. При единственной явной installed используются обычные проверки обеих сторон, при неоднозначности запросы отклоняются.

Reportservice использует один выбор запросов для Build и LookupQueries. Целевая сторона R без installed допускается только с известным repository. Остальные правила отказа сохраняются. Planservice сохраняет дедупликацию и прогресс.

DTO добавляет summary.reinstalls; отсутствующее поле старого результата даёт 0. UI показывает Пересборка и предупреждение для partial/unsupported, общий счётчик только из сводки.

## Risks / Trade-offs

Целевые repository metadata не подтверждают конфигурацию установленной сборки. Получение after без before не делает сравнение доступным. Ранее сохранённый частичный анализ остаётся частичным; нужен новый запуск.

## Validation

Неизменённый fixture, числовые границы, маркеры, side bindings, Analyzer, последовательный и параллельный planservice, HTTP и legacy JSON, браузер. Полные проверки Go и frontend, race для обработки, OpenSpec strict.
