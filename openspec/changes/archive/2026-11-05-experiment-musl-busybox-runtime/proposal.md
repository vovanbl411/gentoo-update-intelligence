# Proposal

## Why

Пользователь хочет проверить Gentoo runtime на musl и BusyBox как отдельный эксперимент после получения рабочего glibc-runtime размером 340 105 258 байт. Нужно измерить совместимость metadata и размер, сохранив штатный glibc workflow.

## What Changes

- Подготовить отдельную базу из официальной Gentoo musl stage3 по digest и прежнего закреплённого snapshot.
- Собрать Git и BusyBox из исходников; сравнить musl с GNU-утилитами и вариант с заменой доступных утилит BusyBox.
- Использовать отдельные локальные теги и временные Compose-проекты.
- Сравнить результаты генерации metadata, зафиксировать необходимые GNU-исключения и ограничения эксперимента.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

Нет. Это opt-in эксперимент сборки, без изменения штатных контрактов; используется `skip_specs: true`.

## Impact

Экспериментальные файлы в `gentoo/`, минимальные opt-in изменения общего экспорта и проверок при необходимости. Штатные Dockerfile, Compose default, glibc-теги и существующие volumes сохраняются. Публикация, commit и push не входят в задачу.
