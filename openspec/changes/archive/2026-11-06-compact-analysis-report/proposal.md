# Proposal

## Why

Результат анализа содержит большие технические JSON-объекты, которые затрудняют просмотр изменений пакетов. Полный ответ также передаётся при обычном открытии отчёта.

## What Changes

- Добавить компактное представление сохранённого задания и результата для frontend.
- Показать сводку, поиск и фильтры пакетов, читаемые findings и metadata diff; технические данные загружать по запросу.
- Сохранить полный API v1, прежние UUID и формат хранения.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `http-api`: компактный endpoint чтения задания и отчёта.
- `analysis-frontend`: сводка и читаемое представление результатов с поиском и фильтрами.

## Impact

Затрагиваются backend HTTP DTO и обработчики, frontend, тесты и документация. Успешная приёмка требует сохранения смысла evidence и ограничений, совместимости полного API и сокращения ответа на представительном fixture.
