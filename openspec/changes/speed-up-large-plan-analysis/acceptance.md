# Проверка

Синтетический benchmark `go test ./internal/planservice -run '^$' -bench '^BenchmarkLargePlan$' -benchtime=3x -count=1`: 40 записей и 80 уникальных запросов, искусственная задержка каждого Lookup — 5 мс. На Intel Core i7-1260P последовательный вариант занял 434 мс на план, параллельный — 208 мс. До изменения отдельный последовательный замер составил 424 мс. Это проверка параллелизма ожидания, а не скорость реальной генерации Gentoo metadata или оценка холодного и тёплого cache.

Для приёмки предоставлен `testdata/parser/ebuild-updates-2.txt`. Сравнение реального холодного и повторного запуска остаётся невыполненным; текущий benchmark не заменяет его.
